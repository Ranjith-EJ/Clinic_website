DR MITHRA HEGDE'S DENTAL SPECIALITY CLINIC — DEMO WEBSITE

FILES
- index.html: website structure and content
- style.css: responsive design and styling
- script.js: mobile navigation, date validation and WhatsApp appointment enquiry

HOW TO RUN
1. Extract the ZIP file.
2. Open the folder.
3. Double-click index.html, or use VS Code Live Server.

IMPORTANT BEFORE PUBLISHING
- Confirm the clinic's exact name, address, phone number and opening hours.
- Confirm the actual treatments offered. The treatment cards in this demo are examples only.
- Add verified doctor qualifications, experience and professional profile details.
- Replace image placeholders/stock images with photographs approved by the clinic.
- Confirm permission to reproduce patient review excerpts and verify the current review count.
- The appointment form is a front-end demo. It opens WhatsApp; it does not save appointments to a database or confirm bookings.
- For production, add a secure backend (for example Django), server-side validation, spam protection, privacy notice/consent, and an appointment management workflow.
- Test the WhatsApp number and Google Maps location before launch.

The page uses Google Fonts, Unsplash-hosted sample photographs and a Google Maps embed, so those elements need an internet connection.
